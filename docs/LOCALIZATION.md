# Localization

| | |
|---|---|
| Languages | Portuguese (`pt`), English (`en`) |
| Default UI language | Portuguese: used for any device language other than English (`resolveAppLocale` in `lib/core/l10n/l10n.dart`). |
| Base (template) language | English — `lib/l10n/app_en.arb` |
| Config | `l10n.yaml` (`nullable-getter: false`, output in `lib/l10n/`) |
| Generated code | `lib/l10n/app_localizations*.dart` (regenerated by `flutter pub get` / `flutter gen-l10n`; excluded from analysis) |

## Usage

```dart
import '../../core/l10n/l10n.dart';

Text(context.l10n.signInAction);
Text(context.l10n.compatibility(score));        // placeholder
showAppSnackBar(context, context.l10n.failureMessage(error));
```

Use `appLocalizationsDelegates` (not `AppLocalizations.localizationsDelegates`) in any `MaterialApp`, including test harnesses: the generated list references the legacy `flutter_localizations` Material/Cupertino delegates, while the widgets come from `material_ui`/`cupertino_ui`.

## Key conventions

- camelCase, English, prefixed by purpose: `nav*`, `*Action` (buttons), `*Label`, `*Title`, `*Body`, `*Hint`, `validation*`, `error*`, `skill*`.
- Placeholders declared in `app_en.arb` with type (`"percent": {"type": "int"}`).
- Skill names: `skill<Id>` and mapped in `Skills.label()` (`lib/features/profile/skills.dart`).

## Dates and numbers

- Chat time: `DateFormat.Hm(locale)` from `intl` → `14:05` in both languages.
- Percentages are integers interpolated into the message (`{percent}% compatível`).

## Error messages

Every `Failure` subclass maps to one `error*` key in `FailureMessages.failureMessage`. Adding a `Failure` subclass is a compile error until it gets a message (exhaustive `switch` on a sealed class).

## Adding a language

1. Copy `app_en.arb` to `app_<code>.arb`, set `@@locale`, translate all values.
2. `flutter gen-l10n` (or `flutter pub get`).
3. If it should become the fallback, change `resolveAppLocale`.
4. iOS: add the language to `CFBundleLocalizations` in `ios/Runner/Info.plist`.

## No hard-coded strings

All user-visible text comes from ARB files. Exceptions: technical messages never shown in the UI (e.g., the `UnsupportedError` in `firebase_options.dart`). Reviewers should reject `Text('...')` with literal user-facing text.
